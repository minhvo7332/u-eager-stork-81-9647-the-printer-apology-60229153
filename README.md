`main.py` writes one line to `/output/entry.txt`: an apology note from an
office printer to the people who keep jamming it, feeding it cheap paper
and swearing at it. The line (118 characters):

> I'm sorry I ate your report. The paper was cheap, the staple was a
> surprise, and your swearing is now in my error log.

Deterministic: the same line on every run, no network, no model calls,
no input read. Run locally with `python3 main.py` (writes `./output/entry.txt`
when `/output` is not writable).
